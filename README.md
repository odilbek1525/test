# Портфолио

Адаптивный сайт-портфолио на React и Vite со сменой языка (русский/английский) и светлой/тёмной темы. Главная страница включает информацию о разработчике, навыки, проекты и контакты. Каталог товаров из предыдущего задания сохранён как отдельная страница `/catalog`. Макеты Feng Shui и PERFUME LINE доступны в разделе проектов и открываются как отдельные статические страницы из `public/projects`.

Каталог загружает все товары из [DummyJSON Products API](https://dummyjson.com/products?limit=0) и показывает их страницами по 12 позиций. Доступны поиск, фильтрация по категориям, сортировка и отдельная страница с подробной информацией о каждом товаре. Если API недоступно, показывается локальный резервный каталог. Загрузка, состояние загрузки и обработка ошибок реализованы с использованием React, Zustand и Axios.

## Персонализация

- Замените текст, контакты и примеры работ в объекте `copy` и массиве `projects` в `src/App.jsx`.
- Положите своё фото вместо `public/profile-photo.svg` и обновите путь в `src/App.jsx`.
- Замените примерные адреса электронной почты и Telegram в секции контактов в `src/App.jsx`.
- В портфолио оставлены только проекты с рабочими демонстрационными страницами.

## Запуск

```sh
npm install
npm run dev
```

## Проверки

```sh
npm run lint
npm run build
```
